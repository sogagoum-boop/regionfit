# 🥗 RégionFit - Mangez Local, Perdez du Poids

![Version](https://img.shields.io/badge/version-1.0-green)
![License](https://img.shields.io/badge/license-Propriétaire-blue)
![Status](https://img.shields.io/badge/status-En%20développement-yellow)

**RégionFit** est une application de perte de poids qui utilise l'**Intelligence Artificielle** (Google Gemini) et la **géolocalisation** pour proposer des repas adaptés à votre région, avec des produits locaux et de saison.

---

## ✨ Fonctionnalités

### 🤖 Intelligence Artificielle
- **Scan de repas par photo** : Analyse instantanée des calories et macros via Google Gemini Vision
- **Scan d'étiquettes** : Décryptage des informations nutritionnelles
- **Génération d'alternatives santé** : Propositions de substituts avec images
- **Coach IA conversationnel** : Assistant 24h/24

### 📍 Géolocalisation & Saisonnalité
- **Produits locaux** : Suggestions adaptées à votre région
- **Fruits et légumes de saison** : Recommandations basées sur le calendrier
- **Plats régionaux** : Recettes traditionnelles adaptées

### 📊 Planning Nutritionnel Intelligent
- **Alternance calorique** : 2000/1500/1000/500 kcal par jour
- **Personnalisation** : Basé sur votre âge, poids, taille, activité
- **Liste de courses automatique** : Générée chaque semaine
